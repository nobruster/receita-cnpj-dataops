# Eval real do AC-6 e rótulo F2-1 (O1/G4)

> **Why:** O relatório chamava de AC-6 a nota do Sentinel (fase 2); o AC-6 do brief é reprocessamento idêntico e não era medido.

---

## Goal

`pipeline.evals --reprocessar` recarrega a competência (carga + dbt + monitores), compara `dq_metrics` antes/depois e dá PASS só se idênticas. A linha do Sentinel vira `F2-1 Sentinel (fase 2)`.

---

## Context

- `pipeline/evals.py`, `tests/test_evals.py`.

Pré-requisitos dos evals: rodar da raiz do repo com `uv sync` feito e `PG_HOST/PG_USER/PG_PASSWORD/PG_DB` apontando para um Postgres de teste.

---

## Success Criteria

```bash
# eval-1: rótulo F2-1 e sem AC-6 Sentinel
eval_1() {
  grep -q 'F2-1' pipeline/evals.py && ! grep -q 'AC-6 Sentinel' pipeline/evals.py
}

# eval-2: flag de reprocessamento
eval_2() {
  grep -q -- '--reprocessar' pipeline/evals.py
}

eval_3() {

}
```
